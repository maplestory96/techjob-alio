# TechJob ALIO | 공기업 EMC·RF·전기전자·교정 특화 채용 허브

공공기관·출연연·공기업의 **EMC 시험(자동차 전장·국방), RF/무선통신, 전기/전자, 계측장비 교정(KOLAS)** 직무 채용 정보만 핀포인트로 수집·분류하고, 의료기기 분야는 자동으로 필터링(제외)해 주는 현대적 SPA 웹 애플리케이션입니다.

---

## 1. 로컬 실행 방법

터미널(PowerShell 또는 VS Code 터미널)에서 프로젝트 폴더로 이동한 뒤 아래 명령어를 실행하세요:

```bash
# 개발 서버 실행 (http://localhost:5173 접속)
npm run dev
```

* 최신 공고 크롤러 수동 실행 (비용 0원):
  ```bash
  npm run crawl
  ```

---

## 2. 주요 구현 기능

1. **4대 타겟 직무 핀포인트 필터링 & 네거티브 필터(의료 제외)**
   * **EMC 시험 (전장·국방)**: CISPR 25, ISO 11452, MIL-STD-461/464, 전자파 챔버 운용
   * **RF / 무선통신**: 안테나 측정, VNA/Spectrum Analyzer, 레이다, 위성통신
   * **전기 / 전자**: 고전압·대전력 시험, 전기안전(KC), 보호계전, 하드웨어 검증
   * **계측장비 교정**: KOLAS 국가교정, 표준기 소급성, 측정불확도 산출
   * **의료 분야 자동 제외**: `의료기기`, `IEC 60601`, `생체의료`, `임상` 키워드가 포함된 공고는 자동으로 걸러지며, 상단 스위치로 차단 내역을 투명하게 확인할 수 있습니다.

2. **깔끔한 카드형 뷰 & D-Day 카운트다운**
   * 오늘 마감(`D-Day`), 마감 임박(`D-3` 이내) 공고 하이라이트 및 마감 임박순 자동 정렬
   * 지역별 / 고용형태별(정규직, 채용형 인턴, 무기계약직 등) 필터 및 추천 태그(`#MIL-STD-461`, `#KOLAS`, `#무선설비기사` 등) 원클릭 검색

3. **채용 전형 캘린더 뷰 (서류 · 발표 · 필기 · 면접)**
   * 월간 달력에서 서류 시작/마감, 서류 발표, 필기시험(NCS/전공), 면접 일정을 색상별 배지로 확인
   * 특정 날짜 클릭 시 우측 패널에서 해당 일자의 전형 상세 타임라인 제공

4. **관심 공고 찜(북마크) & 새 공고 자동 분류 테스트**
   * 서버나 로그인 없이 브라우저 `LocalStorage`에 찜한 공고 영구 보관
   * 상단 **[공고 추가·분류 테스트]** 버튼으로 새 공고 텍스트를 입력하면 실시간으로 직무 매칭 및 의료 제외 여부가 자동 판별됩니다.
